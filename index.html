Scripts

Shell scripts are just the commands you'd type, saved in a file so they can be re-run.

middle.sh

Print lines from the middle of any file.

#!/bin/bash
head -n "$2" "$1" | tail -n "$3"

# bash middle.sh octane.pdb 15 5

sorted.sh

Rank any number of files by length.

wc -l "$@" | sort -n

# bash sorted.sh *.pdb ../creatures/*.dat

Commands I learned

The core toolkit from the first four sessions.

CommandWhat it does
pwd · ls -lhrt · cd ..Find out where I am, see what's here, move around
head · tail · less · catLook inside files without opening them
mkdir · cp · mv · rm -rCreate, copy, move/rename, delete (no undo!)
wc -l · sort -n · cut -d , -f 2 · uniq -cCount, sort, pull out a column, count repeats
| · > · >> · * · ?Chain commands, save or append output, match many files
for f in *.dat; do ...; doneRepeat a command for every file
chmod +x · ./script.shMake a script runnable and run it
git status · add · commit · pushSave snapshots of this project and publish them here

How this repo came together

Workshop sessions, Tuesdays and Thursdays, IRIC 352.

  1. Nov 3

    Navigating the shell. Downloaded the lesson data, learned paths, ls, cd, pipes, and wildcards.

  2. Nov 5

    Working with files. Built thesis_v1, backed up the gyre data to raw/, and learned cut, uniq, and permissions.

  3. Nov 10

    Loops and scripts. Automated repetitive work with for loops and reusable scripts like middle.sh.

  4. Nov 12

    Git and GitHub. Turned this folder into a repository, added a .gitignore, and pushed it here.

Not everything is tracked. A 90 MB UniProt protein file (uniprot_sprot.fasta.gz) lives in my local copy but is kept out of the repository by .gitignore (*.gz, *.fasta). Large data belongs elsewhere; the repo tracks code and small files.
